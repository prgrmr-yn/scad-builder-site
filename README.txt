SCAD Builder

Open index.html in a browser or upload this whole folder to a static host.

Adding models to the library
1. In the app: Library > name your design > Export .json
2. Put the .json file in the models folder
3. Run: python3 tools/make-index.py   (rebuilds models/index.json)
4. Upload the folder again. The model appears for everyone.

The js/lib and data folders hold experimental files that the editor does not load.
